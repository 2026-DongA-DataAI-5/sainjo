# K5 정비 기준 출처 및 이용 승인 체크리스트

기준의 내용 확인과 서비스 내 재사용 승인은 서로 다른 절차입니다. 이 문서는 출처가 맞는지 확인한 사실과, 코드·화면·발표에서 사용할 권한이 확인됐는지를 분리해 관리합니다.

## 2026-10-15 프로토타입 사용 결정

사용자 요청에 따라 출처 대조가 끝난 2021년형 K5 DL3 후보 규칙을 프로토타입 계산에 사용합니다. 결과 화면과 API에는 `사용 권리 확인 중` 상태를 표시합니다. 이는 저작권 이용 허락을 받았다는 뜻도, 기아가 차근을 승인·보증했다는 뜻도 아닙니다. 권리자 문의는 이미 발송했으며 Gmail에서 답변은 확인되지 않았습니다.

저장소 `2026-DongA-DataAI-5/sainjo`는 공개 저장소입니다. 따라서 후보 규칙을 푸시하면 인터넷에서 볼 수 있습니다. 사용자는 현 개발을 진행하도록 요청했으며, 공개 사용의 허용 여부는 여전히 미확인으로 기록합니다. 이 상태에서 정비 기준을 승인된 상용 자료처럼 표현하지 않으며, 공식 원문 문장·표 이미지·PDF를 복사하지 않습니다. 공개 서비스 배포나 권리 상태를 `allowed`로 바꾸는 일은 권리 확인 후 별도로 판단합니다.

## 2026-10-15 추가 확인

기아 공식 취급설명서 PDF의 앞부분에는 ©2020 기아자동차(주) 표시와 함께, 책자 내용의 일부 또는 전체를 사전 서면 동의 없이 인쇄·복사·기록 등으로 복제·재생·배포하지 말라는 고지가 있습니다. [기아 공식 취급설명서 PDF](https://ownersmanual.kia.com/docview/download/pdf/8dc2efef-6b46-4915-836b-ff5a26e8f59f/OM_FULL) 1쪽. 이는 권한 검토가 필요하다는 근거를 강화합니다. 다만 이 고지가 정비표의 사실 수치를 별도로 추출한 데이터베이스, 주기 계산 및 변형된 결과 표시에도 어떻게 적용되는지는 공개 자료만으로 판단하지 않습니다.

기아 대표사이트 이용약관은 회사가 제작한 콘텐츠의 지식재산권이 회사에 귀속된다고 하고, 회사 권리 정보의 영리 목적 이용에 사전 승낙을 요구합니다. [기아 대표사이트 이용약관 제32조](https://m.members.kia.com/kr/view/web/kutl/kutl_app_access.do). 이 약관은 회원과 대표사이트 서비스 이용 범위를 대상으로 하므로, 프로젝트의 비상업 발표 및 공개 GitHub 저장소에 적용되는 정확한 권한을 확정하는 문서로 간주하지 않습니다.

기아 고객센터는 사용설명서 접근 경로와 일반 고객 문의를 안내하며 번호는 080-200-2000입니다. [기아 고객센터 안내](https://www.kia.com/kr/customer-service/center/default). 공개된 안내에서 정비 기준 데이터 재사용 허가 담당 부서나 별도 공개 라이선스는 확인하지 못했습니다. 권리·출판·콘텐츠 담당 부서에 문의했으며 답변을 기다리는 동안 후보 수치를 권리 확인 상태로 표시해 프로토타입에서 계산합니다.

## 권리 확인 중 개발 규칙

- 후보 규칙의 `rights_status`는 `pending_confirmation`, `review_status`는 `source_checked_pending_approval`로 유지합니다. 프로토타입에서는 이 조합의 규칙을 계산에 사용합니다.
- 모든 계산 결과에 `rights_review_pending=true`, `rights_status_label="사용 권리 확인 중"`을 포함하고 화면에 표시합니다. 상태를 숨기거나 권리 허락·기아 승인으로 설명하지 않습니다.
- 권리 확인 전에는 사용자 공개 서비스 배포, `allowed` 상태로 전환, 기아가 검증·보증한 권장 기준이라는 표현을 하지 않습니다. 발표에서도 시연 규칙의 출처와 권리 확인 상태를 함께 설명합니다.
- 일반 주기, 다른 연식·세대·엔진의 주기, 인터넷 게시글의 경험담을 K5 DL3 2021 G2.0의 대체 기준으로 섞지 않습니다.
- 가혹조건은 차량에서 선택한 세부 운행상황 번호가 해당 정비 항목의 매뉴얼 번호와 일치할 때만 적용합니다. '가혹조건' 전체를 모든 정비 항목의 공통 주기로 처리하지 않습니다.
- 취급설명서의 PDF·이미지·긴 문장을 복사해 서비스나 저장소에 넣지 않습니다. 현재 화면의 원문 링크는 사용자가 기아 공식 페이지에서 직접 확인하도록 연결합니다.
- 사용자가 입력한 정비기록은 확인된 정비 증빙과 구분합니다. 기록이 없다는 이유로 미정비라고 단정하지 않습니다.

## 권리자에게 확인할 항목

승인 요청에는 대상과 사용 방식을 구체적으로 적고, 회신 원문·담당 부서·회신일·허용 범위를 보관합니다.

1. 대상 출처: 국내 판매 2021년형 K5 DL3, 2.0 가솔린, 스마트스트림 G2.0 CVVL, 자동변속기 취급설명서의 정비 표.
2. 사용할 사실: 정비 항목, 통상·가혹조건 구분, 거리·개월 기준, 점검 또는 교환 구분.
3. 사용할 방식: 수치를 데이터 파일에 입력하고, 차량 조건과 사용자 입력 기록에 따라 계산된 결과를 화면에 표시.
4. 공개 범위: 부트캠프 비상업 발표용 시연, GitHub 저장소 공개 여부, Pages 데모 공개 여부를 각각 명시.
5. 표시 방식: 출처명·쪽/항목·확인일·공식 링크를 표시하고, 설명서 원문 문장·표 이미지·PDF는 복제하지 않음.
6. 필요한 권한: 해당 수치의 저장·계산·변형된 결과 표시·공개 저장소 포함을 각각 허용하는지, 허용 기간과 조건은 무엇인지.
