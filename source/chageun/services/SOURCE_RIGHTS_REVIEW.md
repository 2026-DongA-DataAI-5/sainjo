# K5 정비 기준 출처 및 이용 승인 체크리스트

기준의 내용 확인과 서비스 내 재사용 승인은 서로 다른 절차입니다. 이 문서는 출처가 맞는지 확인한 사실과, 코드·화면·발표에서 사용할 권한이 확인됐는지를 분리해 관리합니다.

## 현재 확인 결과

| 출처 | 확인된 내용 | K5 DL3 기준으로 사용 | 상태 |
|---|---|---|---|
| [기아 2021 K5 DL3 취급설명서 정기 점검표](https://ownersmanual.kia.com/full_webhelp/DL3/2021/ko_KR/topics/t00735.html) | 고정 사양의 통상·가혹조건별 항목, 주기, 점검 구분을 확인 | 후보 규칙의 내용 근거로 사용 | 출처 대조 완료. 규칙 데이터의 서비스 내 재사용 권한·표시 방식은 미승인 |
| [자동차365 자동차 정비 주기](https://www.car365.go.kr/ccpt/carlife/operate/carImprmnView.do?_menuId=M620302000&moblYn=Y) | 여러 정비 항목의 일반 참고 주기를 안내하고, 상세 주기는 제조사·모델에 따라 다를 수 있다고 명시 | **사용하지 않음** | K5 DL3 개별 기준이 아님. 점화플러그 일반 예시 40,000km는 기아 설명서의 165,000km와 달라 K5 기준으로 적용하면 안 됨 |

기아의 [대표사이트 이용약관](https://m.members.kia.com/kr/view/web/kutl/kutl_app_access.do)은 기아가 작성한 콘텐츠의 지식재산권 귀속을 다룹니다. 다만 이 약관이 K5 취급설명서의 수치형 사실을 정비 계산 데이터로 저장·가공·표시하는 경우에 직접 적용되는지, 또는 이를 별도로 허용하는 공개 라이선스가 있는지는 이번 검토에서 확인하지 못했습니다. 이 일반 약관만으로 허용 또는 금지를 단정하지 않습니다.

## 권한 확인 전 개발 규칙

- 후보 규칙의 `rights_status`는 `pending_confirmation`, `review_status`는 `source_checked_pending_approval`로 유지합니다.
- 위 상태인 규칙은 실제 계정의 계산에 사용하지 않습니다. 이 제한을 풀려면 권리자 또는 적법한 데이터 제공자의 확인 자료를 저장소 변경 이력과 함께 기록해야 합니다.
- 일반 주기, 다른 연식·세대·엔진의 주기, 인터넷 게시글의 경험담을 K5 DL3 2021 G2.0의 대체 기준으로 섞지 않습니다.
- 취급설명서의 PDF·이미지·긴 문장을 복사해 서비스나 저장소에 넣지 않습니다. 현재 화면의 원문 링크는 사용자가 기아 공식 페이지에서 직접 확인하도록 연결합니다.
- 사용자가 입력한 정비기록은 확인된 정비 증빙과 구분합니다. 기록이 없다는 이유로 미정비라고 단정하지 않습니다.

## 권리자에게 확인할 항목

승인 요청에는 대상과 사용 방식을 구체적으로 적고, 회신 원문·담당 부서·회신일·허용 범위를 보관합니다.

1. 대상 출처: 국내 판매 2021년형 K5 DL3, 2.0 가솔린, 스마트스트림 G2.0 CVVL, 자동변속기 취급설명서의 정비 표.
2. 사용할 사실: 정비 항목, 통상·가혹조건 구분, 거리·개월 기준, 점검 또는 교환 구분.
3. 사용할 방식: 수치를 데이터 파일에 입력하고, 차량 조건과 사용자 입력 기록에 따라 계산된 결과를 화면에 표시.
4. 공개 범위: 부트캠프 비상업 발표용 시연, GitHub 저장소 공개 여부, Pages 데모 공개 여부를 각각 명시.
5. 표시 방식: 출처명·쪽/항목·확인일·공식 링크를 표시하고, 설명서 원문 문장·표 이미지·PDF는 복제하지 않음.
6. 필요한 권한: 해당 수치의 저장·계산·변형된 결과 표시·공개 저장소 포함을 각각 허용하는지, 허용 기간과 조건은 무엇인지.

## 권리자 문의 초안

> 안녕하세요. 부트캠프 비상업 미니프로젝트에서 국내 2021년형 K5 DL3 2.0 가솔린 G2.0 CVVL 자동변속기 한 사양의 관리 안내를 시연하려고 합니다. 기아 공식 취급설명서 정기 점검표의 항목명, 통상·가혹조건, 거리·기간 기준, 점검·교환 구분을 데이터로 정리해 차량의 주행거리와 사용자가 입력한 정비이력을 비교하고, 계산 결과와 출처 링크를 화면에 표시할 수 있는지 확인 부탁드립니다. 설명서의 PDF·이미지·긴 원문 문장은 복제하지 않을 예정입니다. 이 이용이 허용되는 범위와 필요한 출처 표시, 공개 GitHub 저장소 및 Pages 시연 공개 가능 여부를 안내해 주시면 감사하겠습니다.

## 활성화 완료 조건

다음 조건이 모두 충족된 뒤에만 후보 규칙을 승인 상태로 바꾸고 재검수합니다.

- 대상 차량 사양과 각 규칙의 근거 범위가 일치함.
- 수치 데이터의 저장·계산·결과 표시·저장소 공개에 대한 권한 또는 적용 가능한 라이선스가 확인됨.
- 회신/라이선스 근거, 출처 표시 요건, 검토자와 검토일이 저장소에 기록됨.
- 테스트가 승인된 규칙만 계산하고, 미승인·불일치 사양은 계속 계산을 차단함.
- 공식 출처·최신 개정 여부와 발표 화면을 다시 확인함.
