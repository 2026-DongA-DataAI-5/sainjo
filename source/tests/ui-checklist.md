## 확인한 주요 동작
- 차량 저장·재조회: 저장 성공 후에만 대시보드로 이동, 재조회 시 입력값 유지
- 기록 저장·삭제: 저장 성공 후에만 타임라인 이동, 삭제는 확인 후 실행
- 0km는 "0km"로 표시, 미확인(null)과 구분
- 메모의 HTML 코드는 실행되지 않고 글자로 표시
- 저장 중 연타해도 차량 1대만 생성 (저장 중에는 버튼과 같은 화면의 링크가 잠김)
- 서버 오류·세션 만료·입력 오류 시 입력값 유지, 완료 안내 없음
- 기록은 localStorage에 저장하지 않음 (차량·기록 키 없음 확인)

## 이번 검수에서 고친 문제
- 저장 중 연타 시 버튼 글자가 바뀌며 옆 링크가 밀려와 저장 전에 다른 화면으로 이동하던 문제 → 글자는 그대로 두고 잠금, 링크도 잠금
- 대시보드가 로딩 전에 가상 예시 차량("K5 DL3")을 보여 주던 문제 → "불러오는 중"으로 표시 후 실제 값 표시

## 확인하지 못한 항목 (남은 작업)
- **'저장 여부 확인 필요' 문구**: 응답을 받지 못한 저장(네트워크 끊김)을 재현하는 방법이 mock에 없어서 자동 테스트하지 못했습니다. 코드 검토로만 확인했습니다.
- 운영 서버(live 모드)와 실제 로그인: 서버 API가 아직 없어서 확인하지 못했습니다. 팀원 2의 API 연결 후 다시 확인해야 합니다.
- 기록 입력의 관리항목은 현재 계약상 `engine-oil`만 저장됩니다. 에어클리너·냉각수를 고르면 "선택할 수 없는 값" 안내가 뜹니다.
- 타임라인은 최대 100건까지만 불러옵니다.
- 로그인 화면(`templates/auth.html`)과 라우트 등록은 팀원 2에게 요청해야 합니다.
- 운행조건(normal/severe) 선택 UI는 아직 없습니다. 기본값 `unknown`만 저장합니다.

- 이 변경은 관리 판단(교환 시기 계산)을 추가하지 않습니다. 관리 안내 화면은 기존 샘플 그대로이며 가상 예시라고 표시되어 있습니다.
